--- PROJECT DESCRIPTION ---
A full-stack Team Task Manager application featuring a React.js frontend dashboard and a Python FastAPI backend. It includes secure user authentication, role-based access control, and real-time task status tracking.

--- TECH STACK ---

Frontend: React.js, Axios, Vite

Backend: FastAPI, Python, Uvicorn

Database: SQLite

Deployment: Railway

--- KEY FEATURES IMPLEMENTED ---

1. Secure User Authentication: Sign up and login functionality using secure JWT access tokens.

2. Role-Based Access Control (RBAC): Distinct views and permissions for "Admin" and "Member" roles.

3. Admin Controls: Backend API with Swagger UI allowing Admins to create new projects and assign tasks to users.

4. Dynamic Task Dashboard: Real-time status tracking allowing users to update their tasks from "Pending" to "In Progress" or "Completed".

--- HOW TO EXECUTE / RUN LOCALLY ---

1. Clone the repository:
   git clone [Paste your GitHub Link Here]
   cd team-task-manager-fullstack

2. Run the Backend (FastAPI):
   - Open a terminal and navigate to the backend folder: `cd backend`
   - Create a virtual environment (optional but recommended): `python -m venv venv`
   - Activate the virtual environment.
   - Install dependencies: `pip install -r requirements.txt`
   - Start the server: `uvicorn main:app --reload`
   - The backend API will run at http://localhost:8000

3. Run the Frontend (React):
   - Open a new terminal and navigate to the frontend folder: `cd frontend`
   - Install dependencies: `npm install`
   - Start the React development server: `npm run dev`
   - The frontend will be accessible at http://localhost:5173
